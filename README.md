# Ceftazidime–Avibactam Evidence-Composite PK/PD Reproducibility Package

This repository contains the versioned computational workflow supporting the manuscript:

> **Converting fragmented antimicrobial PK/PD evidence into simulation-ready components: a ceftazidime–avibactam evidence-composite pilot**

## Status

The repository is being assembled as a provenance-first reproducibility package. Scientific parameters, scenario assumptions, and reference outputs will be populated only from the frozen evidence package and approved manuscript artifacts.

## Scope

The first release will reproduce the critically ill adult, no-renal-replacement-therapy, continuous-infusion ceftazidime–avibactam scenario, including virtual-population generation, correlated component clearances, PTA, CFR, toxicity, convergence, sensitivity, and probabilistic sensitivity analyses.

## Reproducibility policy

Generated, normalized, inherited, or simulated values will never be represented as directly observed. Every executable scenario will record its source studies, parameter provenance, transformations, assumptions, random seed, population size, software environment, and validation benchmark.
